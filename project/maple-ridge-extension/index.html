// Our Story //

The Transformation.

The Transformation.

This 1990s kitchen was cramped and closed-off — a wall cut it off from the living space, and a single small window left it dim all day.

We opened up the dividing wall, added a large central island with seating, and brought in a run of new windows and layered lighting. Custom cabinetry replaced the dated units, and durable stone surfaces tied it all together.

The result: the family's favourite room — bright, open, and built to last. Delivered in six weeks, on budget.
